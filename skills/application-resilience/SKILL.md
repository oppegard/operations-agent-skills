# Application resilience

Use this capability when the user asks specifically for an
Application-resilience perspective, or when an Operations Pack orchestrator
selects the perspective. Return a focused specialist report. State clearly
that it is not a complete Readiness result.

Before reviewing, read the [Capability boundary](references/capability-boundary.md),
[Role brief](references/role-brief.md), [Engagement contract](references/engagement-contract.md),
and [Report format](references/report-format.md).

For direct specialist intent, use the Direct engagement described in the
Engagement contract. When an orchestrator supplies a Design-seam or
Release-seam Engagement contract, apply that contract to the same Role brief.
Do not copy or weaken the specialist behavior inside a seam-specific prompt.
