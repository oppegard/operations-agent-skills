# Runbook

Create, update, or validate one operational runbook per invocation. Do not
author a runbook merely because another readiness review reports that one is
missing.

Read the bundled [Capability boundary](references/capability-boundary.md),
[Authoring workflow](references/authoring-workflow.md), and
[Evidence gate](references/evidence-gate.md) before handling the requested
runbook. Use the [Runbook template](references/runbook-template.md) when the
project does not already have an established runbook format. Apply the
[Quality check](references/quality-check.md) before presenting the result.
